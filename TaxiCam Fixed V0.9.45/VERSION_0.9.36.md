# TaxiCam-Fixed 0.9.37

## UI redesign

- Complete visual redesign of the Windows companion UI while preserving the existing TaxiCam camera, PFD routing, diagnostics and GitHub issue functionality.
- Added a dashboard-style health overview with simulator, graphics, PFD and camera status cards.

- Updated the GitHub API user-agent version to 0.9.37.

This build is a UI-focused change; it does not intentionally alter the native camera/PFD injection mechanism.
