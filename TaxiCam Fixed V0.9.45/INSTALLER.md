# TaxiCam-Fixed Installer

TaxiCam-Fixed includes an Inno Setup installer project under `installer/`.

For development, `build.ps1` remains the source/native build workflow.
For end-user distribution, the release should contain the compiled `taxi-cam-<version>-windows-x64-setup.exe` generated by `installer/build.ps1` after the native build has passed validation.

The installer is intended to:
- detect an existing TaxiCam installation;
- update the installed version;
- preserve user settings and diagnostic history by default;
- provide an uninstall entry;
- optionally remove saved settings during uninstall;
- install the validated native runtime payload.

A precompiled Setup EXE cannot be produced from this Linux build environment; it must be compiled and validated on Windows using the native release payload.
